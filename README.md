# DOPE POS

ライブ会場のドリンク販売用の会計アプリ。スマホ・タブレット・PC のブラウザで動き、複数の端末で売上を共有します。

- 公開中: https://dope-register.tadamichi-azukari.workers.dev/

## できること

| 画面 | 内容 |
| --- | --- |
| レジ | 商品をタップ → 現金かキャッシュレスを選ぶ → お預かりを選ぶ → 会計。会計後はお釣りと渡す商品を画面いっぱいに表示します。打ち間違えたら、その画面から取り消すと注文がカートに戻ります。 |
| 履歴 | 日付ごとの会計一覧。金額や商品名で絞り込めます。取消には理由を残せます。 |
| 集計 | 売上・出た数・客単価・チケット特典額、時間帯別の数、支払い方法別、商品別。テキストのコピーと CSV 保存ができます。 |
| レジ締め | 営業前に準備金を記録し、締めで金種ごとの枚数を数えると、「準備金＋現金売上」との過不足が出ます。過去の締めの記録も見られます。 |
| 設定 | 商品の追加・値段の変更・並べ替え・非表示。端末の名前（履歴に出ます）。 |

### 電波が悪くても止まらない

- 画面のファイルは端末に保存されるので、オフラインでも開けます。
- 会計は先に端末に記録し、「未送信」として溜めておきます。つながったら自動で送ります。同じ会計が二重に届いても 1 件として扱います。
- 他の端末の会計は 5 秒ごとに取り込みます（前回から増えた分だけ）。

### 商品と値段

最初は次の 4 つで始まります。値段は「設定」から変えられます。変えても、それまでの会計の金額は変わりません。

| 区分 | 商品 | 値段 |
| --- | --- | --- |
| 通常 | ドリンク | ¥300 |
| 通常 | ドリンク＋バニラアイス | ¥500 |
| ライブチケット購入者 | ドリンク | ¥0（定価 ¥300） |
| ライブチケット購入者 | ドリンク＋バニラアイス | ¥200（定価 ¥500） |

合計金額はサーバー側で明細から計算し直して保存します。

## ファイル

- `public/` … 画面（`index.html`, `app.js`, `app.css`, オフライン用の `sw.js`, ロゴとアイコン）
- `src/worker.js` … API（`POST /api/sync`）。D1 に会計・商品・レジ締めを保存
- `wrangler.toml` … Cloudflare の設定

## 公開・更新

```bash
npx wrangler d1 create dope-register   # 初回だけ。表示された database_id を wrangler.toml に書く
npx wrangler deploy
```

手元で動かすときは `npx wrangler dev`（D1 は手元のものを使います）。

### パスコード（任意）

URL を知っている人なら誰でも会計できます。スタッフだけに絞りたいときは、パスコードを設定します。

```bash
npx wrangler secret put PASSCODE
```

設定すると、各端末で最初に一度パスコードを聞かれます。
