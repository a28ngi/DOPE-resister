# DOPE レジ

ドリンク販売用のシンプルな会計システム。

- 本番: https://dope-register.a28ngi.workers.dev/ （Cloudflare Workers ＋ D1、ログインなし）
- お試し版（claude.ai アカウントで利用）: https://claude.ai/artifact/FPercdpqnCHx9ua6TvxiTS

## 料金ルール

| ボタン | 金額 |
| --- | --- |
| 通常 ドリンク | ¥300 |
| 通常 ドリンク＋バニラアイス | ¥500 |
| ライブチケット購入者 ドリンク | ¥0（ドリンク代無料） |
| ライブチケット購入者 ドリンク＋バニラアイス | ¥200（アイス代のみ） |

- チケット購入者のドリンクは杯数をカウントしますが、売上には入りません。集計画面で「通常」と「チケット購入者」を分けて表示します。
- 値段を変えるときは `register.html` の `PRICE` を書き換えてください。

## 画面

- **レジ**: ボタンで注文を追加 → お預かりを選ぶとお釣りを表示 → 「会計する」
- **集計**: 日ごと（朝6時区切り）/ 全期間の売上・杯数・アイス数・チケット特典で無料にした額。テキストのコピーとCSV保存ができます。
- **履歴**: 会計の一覧。間違えた会計は「取消」で集計から外せます（「戻す」で復活）。

## データ

- Cloudflare 版: 売上は D1 データベースに保存され、全端末で約10秒ごとに同期します。
  電波が切れても会計はでき、端末に「未送信」として残り、つながったら自動で送られます。
- claude.ai 版: claude.ai の共有データに保存されます。
- `register.html` を直接ブラウザで開いた場合は、その端末の中だけに保存されます。

## Cloudflare に公開する

ファイル構成:

- `register.html` … 画面（全バージョン共通）
- `cloudflare/server.js` … 保存の処理
- `cloudflare/worker.js` … 上の 2 つをまとめた貼り付け用ファイル（`node cloudflare/build.mjs` で作り直す）

ダッシュボードで公開する手順:

1. Cloudflare ダッシュボード →「ストレージとデータベース」→「D1」→ データベースを作成（名前: `dope-register`）
2. 「Workers & Pages」→ 作成 → Worker（Hello World）を名前 `dope-register` で作成してデプロイ
3. 「コードを編集」で中身を全部消し、`cloudflare/worker.js` の中身を貼り付けてデプロイ
4. Worker の「設定」→「バインディング」→ D1 データベースを追加（変数名 `DB`、データベース `dope-register`）
5. `https://dope-register.<あなたのサブドメイン>.workers.dev` を開く

ログインはありません。URL を知っている人は誰でも会計を記録できるので、URL はスタッフにだけ共有してください。
